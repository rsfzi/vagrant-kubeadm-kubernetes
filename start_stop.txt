To Shutdown:
1.  delete all deployments
2.  Drain all nodes excluding the control plane:
    vagrant ssh controlplane
    kubectl drain --ignore-daemonsets  --delete-emptydir-data node02
    kubectl drain --ignore-daemonsets  --delete-emptydir-data node01
3.  Shut down nodes:
    ssh node02
      sudo /vagrant/scripts/shutdown_node.sh
    ssh node01
      sudo /vagrant/scripts/shutdown_node.sh
    ssh controlplane
      sudo /vagrant/scripts/shutdown_node.sh
4.  check with vagrant status

To Start:
1.  Start nodes:
    vagrant up controlplane
    vagrant up node01
    vagrant up node02
2.  Start cluster:
    vagrant ssh controlplane
    kubectl uncordon node01
    kubectl uncordon node02



Restart a single pod:
kubectl rollout restart deployment prometheus  -n prometheus
