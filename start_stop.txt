To Shutdown:
1.  delete all deployments
2.  Drain all nodes excluding the control plane:
    kubectl drain --ignore-daemonsets  --delete-emptydir-data node02
    kubectl drain --ignore-daemonsets  --delete-emptydir-data node01
3.  Shut down nodes:
    ssh node02
      sudo /vagrant/scripts/shutdown_node.sh
    ssh node01
      sudo /vagrant/scripts/shutdown_node.sh
    ssh controlplane
      sudo /vagrant/scripts/shutdown_node.sh
4.  check with vagrant status


Shut down all components but kube-apiserver and etcd. – If using kubelet to manage components (kubeadm), just move the manifests out of the /etc/kubernetes/manifests dir and kubelet will stop the containers gracefully.
5.  shut down kube-apiserver
6.  Stop kubelet on control plane, just ensure the etcd leader is the last one to be stopped.
7.  Backup dirs/etcd if needed.

Bringing it backup is essentially the opposite order.

Restart single pod:
kubectl rollout restart deployment prometheus  -n prometheus
